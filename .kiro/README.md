# Kiro project notes

## Project
Expense & Budget Visualizer

## Constraints
- HTML for page structure
- One CSS file in `css/`
- Vanilla JavaScript (no React, Vue, or other application framework)
- One JavaScript file in `js/`
- No backend server
- Browser Local Storage for client-side persistence
- Compatible with modern browsers
- Responsive, clean, minimal, and easy-to-use interface

## Required functionality
- Transaction form: item name, amount, and category
- Validate that required fields are completed and amount is greater than zero
- Add and delete transactions
- Display all transactions with name, amount, and category
- Automatically update the total balance
- Display a pie chart showing spending distribution by category
